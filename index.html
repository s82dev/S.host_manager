⚡ S.HOST
Der einfachste Minecraft Test-Server Manager für deine Welten
⬇ S.HOST herunterladen (.zip)

🎮 Java & Bedrock

Spiele mit Freunden auf PC, Smartphone oder Konsole. S.HOST lädt auf Wunsch automatisch GeyserMC und Floodgate herunter.

🌐 Google Drive Import

Kopiere einfach den Freigabe-Link deiner world.zip. S.HOST entpackt und startet deine Test-Welt direkt.

💻 Einfache Web-UI

Steuere den Server direkt über deinen Browser – mit Live-Konsole, Befehlseingabe und übersichtlichen Controls.

🚀 Schnellstart Anleitung

  1. Lade das S.HOST Archiv (.zip) oben herunter und entpacke es.
  2. Installiere die Voraussetzungen (Python 3 & Java 17+).
  3. Öffne das Terminal im Ordner und installiere Flask: pip install flask
  4. Starte S.HOST mit: python shost.py
  5. Öffne http://localhost:5000 in deinem Browser!
